## 01. About me

I am a technology professional focused on **Data Engineering**, interested in building solutions that transform raw data into reliable, structured and valuable information.

My work and studies involve data processing, automation, ETL pipelines, database management and business intelligence.

I enjoy understanding the entire data lifecycle — from ingestion and transformation to storage, analysis and visualization.

**Areas of interest**

- Data Engineering & ETL Architecture
- Distributed Data Processing
- Data Integration & Automation
- Database Design & SQL
- Cloud Computing & Data Platforms
